A lightweight, customizable autoclicker designed to automate repetitive mouse clicks with precision and low latency.

Features
Custom Interval Control: Set click speed in milliseconds, seconds, or minutes.

Hotkey Activation: Toggle clicking on/off instantly with a single customizable keypress. (F6)

Click Options: Supports left, right, and middle mouse button actions, along with single or double-click modes.

Minimal Footprint: Runs efficiently in the background without high CPU usage.

Built With
Language: Python / C++ (adjust to your language)

Libraries: pynput / pyautogui / Win32 API (adjust as needed)

Getting Started
Installation
Clone the repository:

Bash
git clone https://github.com/your-username/autoclicker.git
Navigate to the folder:

Bash
cd autoclicker
Run the application or script:

Bash
python main.py
Usage
Launch the app and set your desired Click Interval.

Set your Hotkey (default: F6).

Press the hotkey to start clicking, and press it again to stop.
